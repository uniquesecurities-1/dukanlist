🎨 How to use these mockups

Option 1: Open this file in a browser, screenshot each card (use Win+Shift+S), save as PNG, upload to Instagram Ads Manager.

Option 2: Open in Canva → File → Create new design 1080×1080 → recreate the layout using the brand colours below. Canva has all the fonts and the saffron palette is one search away.

Brand colours: #D97706 (saffron) · #92400E (saffron deep) · #FBBF24 (gold) · #FFFBEB (cream) · #0F172A (ink) · #25D366 (WhatsApp green)

Fonts: Manrope 800–900 for headlines · Plus Jakarta Sans 500–700 for body · Noto Sans Devanagari for Hindi

Real shop photos: Get permission from 4–6 well-known Dabwali shopkeepers to use their shopfront photos in Creative #5. Pay them in advertising goodwill (mention them in posts).
