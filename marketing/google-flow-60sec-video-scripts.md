## 🎞️ HOW TO ASSEMBLE THE 60-SECOND VIDEO

### Step 1: Generate all 6 clips in Google Flow
- Paste each **🎥 Video Prompt** into Flow one by one
- Generate 10-second clip for each (Flow allows this)
- Download each clip

### Step 2: Add voiceover
- Option A: Record yourself (natural, personal touch)
- Option B: Use **ElevenLabs** / **Google TTS** with Hindi female voice — paste the 🎤 Voiceover text
- Option C: Add captions only (mute video) — captions text is provided

### Step 3: Add on-screen text
- Use **CapCut** / **Canva Video** / **VN Editor** (all free)
- Layer the 📝 On-Screen Text on top of each clip
- Font: **Noto Sans Devanagari Bold** (Hindi) + **Manrope Bold** (English)
- Color: Saffron `#FF6B1A` on white, or white on saffron

### Step 4: Add transitions
- Simple fade/dissolve between clips (0.3 sec transition)
- Consistent background music: light Punjabi/dhol beat, low volume

### Step 5: Add music
- Suggested: Light bhangra beat or acoustic Indian instrument (dhol + tabla)
- Volume: 20-30% (voiceover primary)
- Royalty-free source: YouTube Audio Library, Uppbeat.io

### Step 6: Export
- **Resolution:** 1080x1920 (9:16 vertical)
- **Format:** MP4 (H.264)
- **File size:** Under 16 MB (WhatsApp Status limit)
- **Duration:** Exactly 60 seconds

## 🚨 IF FLOW GENERATES A DIFFERENT GIRL

If Flow substitutes a random face despite reference image:
1. **Regenerate** with the reference image re-uploaded fresh
2. Add to end of prompt: `"exactly the same person as the reference image, do not modify her face"`
3. Lower the prompt's other descriptive weight — Flow sometimes over-imagines when there's too much scene detail
4. Try Flow's "character consistency" or "identity lock" mode if available in your version
5. As last resort, generate multiple times and pick the take where the face matches best
