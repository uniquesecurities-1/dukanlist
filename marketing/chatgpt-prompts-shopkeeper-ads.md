## 💡 Tips for using ChatGPT image generation effectively

### 1. Use ChatGPT-4 with image generation enabled (Plus subscription)
The free version doesn't generate images. Either use Plus ($20/mo) OR use **Bing Image Creator** (free, powered by DALL-E 3) at `bing.com/create`.

### 2. If a prompt gives a wrong result
Try one of these tweaks:
- Add "high quality, professional, Indian small town" to the end
- Specify "no text in the image" if AI keeps adding garbled text — then add text yourself in Canva
- Try Bing if ChatGPT struggles — same DALL-E 3, different results sometimes

### 3. Editing text in the AI image
DALL-E sometimes generates garbled English text in images. Fix:
- Open the PNG in Canva (free)
- Add a text overlay yourself with the exact words
- Use Manrope font, weight 800, saffron color
- Export as PNG and use that final version

### 4. Consistency across all 10 ads
After generating each image, use the same color filter / preset in Canva (saffron warmth) so the campaign feels cohesive.

### 5. If you don't have a brand logo PNG
Create a simple one in Canva:
- Text "🥇 DukanList"
- Manrope 900 font
- Saffron color #D97706
- Save as transparent PNG
- Drop on every ad's bottom corner

## 🚨 What NOT to claim (honesty checklist)

- ❌ "1000+ shops" or any specific number you can't verify
- ❌ "Best directory in Punjab/Haryana"
- ❌ "India's #1 local app"
- ❌ "Used by millions"
- ❌ "Pehle se 10,000 customers" — unless actually true
- ❌ "Verified shops" — only say this if shop is actually verified
- ❌ Promising specific results ("Aapko 100 customers milenge")

### ✅ What you CAN claim safely

- ✅ "FREE forever · no commission" — true
- ✅ "Made for Mandi Dabwali / Sirsa / Bathinda / Mansa / Muktsar" — true (your target region)
- ✅ "2 minutes me list ho jao" — true if registration is genuinely fast
- ✅ "Photos, WhatsApp, reviews — sab free" — true
- ✅ "DigiMutual Goals Pvt. Ltd. द्वारा संचालित" — true legal entity
- ✅ "Local team — your area, your people" — true
- ✅ "No paid ranking" — true (assuming you don't add this later)
