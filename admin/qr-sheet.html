🖨 QR Sheet — 4 shops on one A4

Pick up to 4 shops, choose the QR type, print one A4 and cut into 4 cards. No paper wasted.
1️⃣ QR type to add
Scanning opens the shop page with the review box already open — best for the billing counter.
2️⃣ Pick shops 0 / 4
The same shop can be added more than once — handy for one Review card and one Profile card. Each card below has its own ⭐/🏪 switch, so changing one never touches the others.
3️⃣ Print
In the print dialog set Margins: None and Scale: 100% (uncheck “Fit to page”), and turn Background graphics ON. Cut along the dashed lines — each card is A6 (105 × 148 mm).
Empty slots print blank, so you can reuse that part of the sheet later.
