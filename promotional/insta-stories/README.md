# Instagram Story Promotional Kit

DukanList ke liye 6-slide Instagram story series. Sab kuch ready hai, bas browser mein open kariye aur PNG download kariye.

---

## ★ Quick Start

1. **`gallery.html`** ko Chrome / Edge mein open kariye (double-click karein on file).
2. Top par bada **"Download All 6 Slides as PNG"** button hai — click karein, saari 6 slides aapke Downloads folder mein chali jaayengi (1080×1920 PNG, Instagram-ready).
3. Instagram app → Story → Gallery se PNG select kariye → post kariye.
4. Caption ke liye **`captions.md`** open kariye — har slide ka Hindi caption ready hai.

---

## ❖ Hindi text render kyon hota hai?

SVG files Windows ke built-in **Nirmala UI** font use karti hain Hindi/Devanagari ke liye. Jab browser mein open karein, sab text perfect dikhega. Agar text ki jagah box (▢) dikhe, to system ka Devanagari font missing hai (rare).

---

## ► Canva mein use karna ho to:

Each `.svg` file ko **Canva → Upload media → Drop SVG** se add kar sakte hain. Phir us par apne shop ki photo / logo / colors customize kar sakte hain.

---

## ☞ Posting strategy

`captions.md` mein detail diya hua hai — kab kya post karna, kaunsa sticker lagana, link sticker kahan zaroori hai.
