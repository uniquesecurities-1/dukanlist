DukanList — Instagram Story Gallery

6 ready-to-post slides. Click "Download PNG" on each card to save 1080×1920 image for Instagram Story upload.

★ कैसे use karein:

  1. Har slide ka "Download PNG" button click kariye — 1080×1920 image aapke Downloads folder mein save ho jaayegi.
  2. Saari slides ek saath chahiye to "Download All" use kariye (browser pop-up allow kariye).
  3. Instagram app open kariye → Story → Gallery se PNG select kariye → post kariye.
  4. Har slide ke saath caption file mein ek matching Hindi caption mila hai — wo bhi copy karke use kariye.
