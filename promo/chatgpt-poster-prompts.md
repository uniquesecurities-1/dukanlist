## 💡 Tips for Best Results

1. **Use ChatGPT-4 / DALL-E 3** for highest quality — paste the prompt as-is.
2. **Iterate twice:** If first output isn't perfect, regenerate with the SAME prompt — DALL-E gives variations.
3. **If text comes out wrong** (AI image generators sometimes mangle text), add at the end of the prompt:
   ```
   IMPORTANT: All text must be perfectly legible. Render English and Devanagari script clearly without spelling errors.
   ```
4. **Download in highest resolution** offered (1080p+).
5. **WhatsApp share workflow:**
   - Generate poster → Save to phone
   - Open WhatsApp → Send to contact → Attach image
   - Add small caption: *"Aapke profession ke liye special platform: dukanlist.com/pro"*
