# 🎯 Quick Usage Guide

## How to use these prompts

1. **Pick prompt block** (visual + overlay text together) and paste into ChatGPT/Sora/Midjourney
2. **Generate image** — let model do 4 variations
3. **Pick best** + run follow-up: *"Same image, but make the phone screen UI text sharper and the headline more readable."*
4. **Caption + hashtags** copy-paste into Instagram
5. **Promote with budget:** Start with ₹200/day per ad, target audience = Dabwali, Sirsa, Bathinda + nearby (50km radius), age 25-55, interest = small business, retail, local shops, entrepreneurship

## Recommended posting order

**Week 1 — Awareness:**
- Day 1: AD 1 (Aspirational — establish brand)
- Day 3: AD 4 (Pucho Bhai introduction)
- Day 5: AD 2 (Social proof — 100+ shops)

**Week 2 — Conversion:**
- Day 8: AD 3 (Value bomb — ₹0)
- Day 11: AD 5 (Pucho Bhai problem-aware)
- Day 14: AD 6 (Pucho Bhai brand hook)

## A/B testing tip

Run 2 ads same day, same audience, ₹100 each — after 24 hours kill the lower-performing one, scale the winner to ₹500/day.

## Image refinement prompt (always run after generation)

> "Same image but: (1) make all text overlay 30% more readable with subtle drop shadow, (2) sharpen the phone screen UI so app interface text is crisp, (3) keep all warm cinematic color grading, (4) save as high-resolution 1080x1080 square."
